# Project Constitution: Mahmud Hasan 3D Portfolio

## 1. Core Engineering Principles
- **Aesthetic Benchmark**: The portfolio must deliver the world-class, award-winning visual fidelity of `aengel.io` (Awwwards / FWA level), including monolithic brutalist typography, cybernetic blueprint grid, holographic 3D ribbon carousel / Stargate portal, specimen ticket HUD, and procedural Web Audio.
- **Identity & Personal Branding**:
  - Primary Identity: **MAHMUD** / **MAHMUD HASAN**
  - Primary Role: **AI ARCHITECT & DESIGN ENGINEER** (AI Agents, High-Craft Full Stack, Mobile Systems)
  - Domain & Brand: `mahmud.dev` // © 2026
  - Contact: `contact@mahmud.dev` (or direct user social channels)
  - Absolutely zero third-party branding (no "AENGEL", no "contact@aengel.io").
- **Performance & Reliability**:
  - Must run with zero console errors, zero failed network fetches, and zero CORS errors.
  - Local asset autonomy: all GLBs, KTX2 textures, fonts, and images must resolve locally with proper MIME types.
  - Smooth 60 FPS WebGPU / WebGL2 rendering pipeline with graceful fallback.

## 2. Tech Stack & Standards
- **Framework**: Next.js App Router, React 19, TypeScript
- **3D & Shaders**: Three.js, TSL / GLSL, WebGPU / WebGL2, Draco decompression, KTX2 BC7 textures
- **Styling**: Tailwind CSS + Cybernetic Modular CSS
- **Audio**: Web Audio API procedural synthesis + spatial ambient sound
