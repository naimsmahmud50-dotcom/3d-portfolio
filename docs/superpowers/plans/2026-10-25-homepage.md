## 🎯 Target Architecture & Aesthetics

1. **Framework:** Next.js (App Router) + TypeScript + Tailwind CSS + Lenis Smooth Scroll.
2. **3D Core:** Three.js + Custom GLSL/WGSL Shaders (Raymarched Neural Core responding to cursor, scroll, and audio).
3. **Audio Synthesis:** Procedural Web Audio API sound designer (`AudioContext`, oscillator, dynamics compressor, subtle UI haptics).
4. **Hero & Typography:** Clean, luxury tech typography (League Spartan / Inter Display + Manrope Mono style), animated reveal, coordinate stamps (`DHAKA, BD · 23.8103°N, 90.4125°E`).
5. **Interactive Edge (Beyond aengel.io):** An embedded live **AI Agent Terminal** right on the homepage where visitors can interact with simulated agent commands.
6. **Bento Grid & Work Preview:** High-contrast, minimal luxury cards previewing flagship work and engineering superpowers.
